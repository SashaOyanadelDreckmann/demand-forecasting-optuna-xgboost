# Demand Forecasting with Optuna & XGBoost

Caso académico de predicción de demanda, diseño de variables y optimización de hiperparámetros.

**Stack:** Python · XGBoost · Optuna · scikit-learn

_Trabajo académico — Universidad de Chile._

## Contenido

- `Lab6_enunciado.ipynb`: flujo de entrenamiento y evaluación.
- `sales.csv`: datos de entrada del ejercicio.
- `modelo_*.pkl` y `xgb_booster.pkl`: artefactos de modelos generados durante la experimentación.

## Uso

Abrir el notebook en un entorno con Python, XGBoost, Optuna y scikit-learn.
